# Contributing to fp_csp_binder

Thank you for your interest in fp_csp_binder.

## How development works

fp_csp_binder is developed internally at EnduroSat and published here as a
read-only mirror: every change to `main` and every release tag is pushed from
our internal repository. We do not merge pull requests on GitHub directly.
When we accept a contribution, we apply it internally and it reaches this
repository through the mirror, with you credited in the commit.

## Reporting issues

- **Bugs and feature requests:** open a GitHub issue using one of the templates.
- **Security vulnerabilities:** do not open an issue; follow [SECURITY.md](SECURITY.md).

## Pull requests

1. Open an issue first for anything beyond a small fix, so we can agree on the approach.
2. Keep each pull request focused on one change, with tests where they apply.
3. Follow the existing code style and run the test suite before submitting.
4. Describe what the change does and why in the pull request description.
